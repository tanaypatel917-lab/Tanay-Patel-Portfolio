# Local typefaces

All delivered fonts were found through the free catalogues at https://uncut.wtf/ and
https://www.freefaces.gallery/ and are self-hosted here. The delivered page does not
require a font CDN at runtime.

## Overused Grotesk (variable)

- Catalogue: https://uncut.wtf/sans-serif/overused-grotesk/
- Upstream repository: https://github.com/RandomMaerks/Overused-Grotesk
- Creator: Bao Nguyen / RandomMaerks
- File used: `overused-grotesk/OverusedGrotesk-VF.woff2` (axes: `wght` 300-900, `slnt` -10-0)
- License: SIL Open Font License 1.1; see `overused-grotesk/LICENSE.txt`
- Portfolio role: display and body sans. A Swiss neo-grotesk in the Helvetica /
  Neue Haas lineage used by the reference sites, with tabular figures for proof values.

## Fragment Mono

- Catalogue: https://uncut.wtf/monospace/fragment-mono/
- Upstream repository: https://github.com/weiweihuanghuang/fragment-mono
- Creator: Wei Huang
- Files used: `fragment-mono/FragmentMono-Regular.woff2`, `fragment-mono/FragmentMono-Italic.woff2`
- License: SIL Open Font License 1.1; see `fragment-mono/OFL.txt`
- Portfolio role: technical labels, status, navigation metadata. Fragment Mono is drawn
  from Helvetica proportions, so it sits naturally next to Overused Grotesk.

## Redaction

- Catalogue: https://uncut.wtf/serif/redaction/
- Official release: https://www.redaction.us/ (`/static/redaction.zip`, version 2.001)
- Designers: Jeremy Mickel (MCKL) with Forest Young, for The Redaction by Titus Kaphar and
  Reginald Dwayne Betts
- Files used: `redaction/Redaction-Regular.woff2`, `redaction/Redaction-Italic.woff2`, and the
  degraded grades `redaction/Redaction_20-Regular.woff2`, `redaction/Redaction_50-Regular.woff2`,
  `redaction/Redaction_100-Regular.woff2`
- License: SIL Open Font License 1.1 (dual licensed with LGPL 2.1); see `redaction/OFL.txt`
- Portfolio role: the italic carries one emphasised phrase per statement; the bitmap grades
  resolve from 100 to Regular in the intro counter and set the ghost wordmark in the footer,
  echoing the dithered portrait.

## Retired

`uncut-sans/` and `steps-mono/` were the previous pairing. They are no longer referenced
by any stylesheet and can be deleted.
